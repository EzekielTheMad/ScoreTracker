# Score Tracker

Offline-first PWA for tracking board game scores at the table. IndexedDB
(Dexie) is the local source of truth — everything works with zero network.
Supabase sync is scaffolded behind a feature flag but not wired yet.

## Stack

Next.js (App Router) · TypeScript · Tailwind · Dexie · Vercel

```bash
npm run dev     # local dev
npm test        # engine/calculator unit tests (vitest)
npm run build   # production build
```

## How scoring works

Board game scoring isn't uniform, so one engine renders the right UI and
runs the right math from a **versioned game definition** (`lib/catalog/`):

- **Fields** describe the score sheet. A `number` field is a direct entry,
  optionally with simple math-as-data (`floor(value / per) × points`, e.g.
  7 Wonders coins). A `calculated` field feeds several inputs into a named
  **calculator function** from the registry (`lib/engine/calculators.ts`)
  for math too ugly to express as data — e.g. 7 Wonders science:
  `a² + b² + c² + 7 × min(a, b, c)`.
- **Scoring modes**: `endgame` (fill-in sheet, 7 Wonders), `tally`
  (running score during play, Carcassonne), `hybrid` (live track plus
  end-game bonuses, Lords of Waterdeep).
- **Expansions** are patches on a base definition that add or remove
  fields (7 Wonders Leaders/Cities).
- Every recorded result **snapshots the resolved definition** (base +
  expansions + versions) it was scored with, so history stays accurate
  when definitions change later.

Two data concepts: the bundled **catalog** of definitions ships in the
build; the per-user **collection** is the games you've added from it.
Players are saved profiles, not logins.

## PWA

Installs standalone on iOS Safari and Android Chrome: web manifest +
apple-touch meta, a small hand-rolled service worker for the offline app
shell (`public/sw.js`), persistent-storage request so iOS doesn't evict
IndexedDB, and safe-area inset handling for notch/home indicator.

Icons are generated by `node scripts/generate-icons.mjs` (requires the
`sharp` dev dependency) and committed under `public/icons/`.
